# NotchBrowser

MacBook のノッチに住む、小さな WebKit ブラウザです。

ノッチにカーソルを乗せるとブラウザが広がり、離すと閉じます。メールやカレンダーなど、よく見るサイトをすぐに開けます。

## インストール

1. [Releases](https://github.com/satoshi0817/notch-browser/releases/latest) から `NotchBrowser-*.zip` をダウンロードして展開します。
2. `NotchBrowser.app` を「アプリケーション」フォルダに移動して開きます。
3. 初回に「インターネットからダウンロードしたアプリ」として確認された場合は、「開く」を選びます。

配布ZIPはDeveloper ID署名・Apple公証済みです。

**動作環境:** macOS 14 以降（Apple Silicon / Intel）。ノッチのない Mac や外部ディスプレイでは、画面上端の中央に表示されます。

## 使い方

| 操作 | |
|---|---|
| 開く | ノッチにカーソルを乗せる / クリック / `⌃⌥N` |
| 閉じる | カーソルを外す / `Esc` / ほかの場所をクリック / `⌃⌥N` |
| 新規タブ・閉じる | `⌘T` / `⌘W` |
| アドレスバー | `⌘L` |
| タブ切り替え | `⌘1`〜`⌘9` |
| タブ検索 | `⌘⇧A`（上下キーで選択、Returnで移動） |
| ページ内検索 | `⌘F`（Returnで次、Shift+Returnで前） |
| 拡大・縮小・リセット | `⌘+` / `⌘-` / `⌘0` |
| 閉じたタブを戻す | `⌘⇧T` |
| クイックメモ | `⌘⇧M` |
| 設定 | `⌘,` またはメニューバーのアイコン |
| 終了 | ブラウザ右上の電源ボタン / ノッチを右クリック › 終了 / メニューバーのアイコン / `⌘Q` |

カーソルを乗せて開いただけのときは、入力は元のアプリのままです。クリックするか `⌃⌥N` で開くと、ブラウザに文字を入力できます。操作した後も、カーソルを外すと設定した待ち時間で閉じます（ピン留め中とダイアログ表示中を除きます）。

ブラウザ右上のピンを押すと、カーソルを外しても開いたままになります。

## 機能

- **ファイル棚:** ファイルのドラッグ開始で小さな棚が開きます。複数選択での取り出し、Spaceでプレビュー、ピン留め、再起動後の復元に対応。元ファイルは移動・削除せず、取り出す時はコピーします。ファイルが残っている間は棚を表示し続けます。同時追加はスタックになり、展開して個別に整理できます。「選択をクリア」「すべてクリア」「クリアを戻す」を用意しています。取り出し成功後は棚から外し、ピン留めした項目は残します（設定で変更可能）。「設定 › ファイル棚」で接近時だけ表示／手動表示へ変更できます。

- **ガラスの背景と枠:** ノッチの従来の形と1段の操作配置を保ち、背景・枠をガラス素材に。設定の「一般」で濃度を調整できます。macOS 26以降は純正Liquid Glass、14/15はぼかし素材で表示します。
- **ページの操作:** アドレスバー右の操作メニューから、ページ内検索、ズーム、URLコピー、タブ検索・復元、自動更新、クイックメモを使えます。
- **自動更新:** タブごとに30秒・1分・5分間隔を選択できます。初期状態はオフ。入力中のページも再読み込みされるため、閲覧用ダッシュボードなどに使ってください。タブを閉じる・プロファイルを切り替えると停止します。
- **クイックメモ:** このMacにプロファイル別で自動保存。見ているページのタイトルとURLを添付できます。プロファイル削除時には、そのメモも削除します。
- **閉じたタブの復元:** 通常タブを最大20件まで、URL・プロファイル・ズーム付きで復元します。アプリ終了時に履歴を破棄します。
- **新規タブ:** 固定ページをカードで表示し、すぐに移動できます。アイコンは操作部品を含め、すべてSF Symbolsで統一しています。以前の絵文字・画像・favicon設定は自動シンボル表示になります。

- **開閉の動き:** 設定の「動き」で、カーソルを乗せてから開く・外してから閉じる待ち時間（0〜3秒）、動き方（自然な加速・減速／ゆっくり加速・減速／一定速度／なし）、開閉それぞれのアニメーション時間（0.05〜1.5秒）を変更できます。クリックやショートカットは待たずに開きます。枠の伸縮と内容のフェードをずらし、開閉の途中で反転しても現在の位置からつながります。設定内の「動きを確認」で試せます。
- **固定タブ:** 名前・URL・アイコン（SF Symbolsから選択 / URLによる自動選択）を設定できます。アイコンのみの表示や、ドラッグでの並べ替えもできます。
- **プロファイル:** ログイン情報（Cookie）をプロファイルごとに分けられます。タブごとにプロファイルを選べます。
- **ディスプレイごとの設定:** 表示するディスプレイ、待機時の不透明度、開いたときのサイズを設定できます。
- **次の予定までの分数:** 予定の 30 分前（変更可）から、閉じたノッチの横に残り時間を表示します。Mac の「カレンダー」アプリの予定を使います。
- **画面共有に映らない:** Zoom や Google Meet などで画面を共有しても、ノッチのブラウザは相手に映りません（一部のアプリでは効かない場合があります）。
- **その他:** ノッチを開いたときに表示するタブの指定、Raycast / Alfred / Spotlight を開いたときにその後ろへ下がる動作。

## 制限

- ファイル棚の初期版は、ファイルURLとして渡されるファイル・フォルダに対応します。Mail添付やWeb画像など、ドロップ時に生成されるデータは先にファイルとして保存してください。移動・削除された元ファイルは棚から利用できなくなる場合があります。
- スリープ抑止は無操作による本体スリープのみが対象です。蓋閉じや手動スリープを防ぎません。音量・ミュートの操作に対応しない外部出力機器では該当項目が無効になります。

- 表示できるのは Web サイトだけです。macOS ではほかのアプリのウィンドウを埋め込めないため、Slack などは Web 版を使ってください。

## ソースからビルド

macOS 26 SDKを含むXcode 26以降（または対応するCommand Line Tools）が必要です。実行対象はmacOS 14以降です。

```sh
./scripts/build-app.sh               # build/NotchBrowser.app（このMacのアーキテクチャ）
./scripts/build-app.sh --universal   # Apple Silicon + Intel
open build/NotchBrowser.app
```

リリース用の zip は `./scripts/release.sh` で作れます。公開時は以下の署名・公証を行い、`--notarize <profile> --publish` を付けると、タグを付けて GitHub Release を公開します。

### Developer ID 署名と Apple 公証

キーチェーンに秘密鍵付きの Developer ID Application 証明書がある Mac では、次のように署名済み ZIP を作れます。

```sh
export SIGNING_IDENTITY='Developer ID Application: SATOSHI SUZUKI (4LPTZP2QZM)'
./scripts/release.sh
```

署名時は Hardened Runtime と安全なタイムスタンプを有効にします。`SIGNING_IDENTITY` 未指定の場合は開発用のアドホック署名です。署名だけでは公証済みにはなりません。

公証には、`xcrun notarytool store-credentials NotchBrowser` で認証情報をキーチェーンに保存してから、同じ環境変数を設定して実行します。秘密鍵やパスワードはリポジトリに保存しないでください。

```sh
./scripts/release.sh --notarize NotchBrowser
```

Apple の受理を確認した後、アプリに公証チケットを添付し、Gatekeeper の検証を通して ZIP を作り直します。公証結果は `build/notarization-result.json` に保存します。

### 設定と上部の操作

設定タブの重複したタイトルやキャッチコピーを省き、選択中のタブを落ち着いた背景で示します。「動き」「ディスプレイ」はプリセットカードから選べます。「カスタム」を開くと詳細を編集でき、「保存」で反映して閉じます。キャンセルでは変更を破棄します。スライダーは数値入力と＋／−でも調整できます。

URLは上部の検索ボタンか `⌘L` で表示・編集できます。ホームボタンは固定ページの設定URLへ戻ります。狭い幅では「進む」「再読み込み」を操作メニューにまとめます。設定・外部ブラウザで開く・終了も同じメニューから利用できます。

### アップデートの通知

起動中は1日1回、GitHub Releasesの最新の正式版を確認します。新しいバージョンがあれば「リリースを開く」「あとで」「このバージョンをスキップ」を選べます。「あとで」は翌日以降に再通知し、スキップはそのバージョンだけを対象にします。状態は再起動後も保持します。

設定 › 一般 › アップデートから自動確認をオフにできます。メニューバーと設定の「アップデートを確認」は、自動確認オフ・スキップ中でも手動で確認できます。ダウンロードとアプリの置き換えはリリースページから行います。この通知機能を使うには、最初にv0.2.2以降へ更新してください。

確認には[GitHubの最新リリースAPI](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)を使います。公開リポジトリへの認証なしのリクエストで、タブ・URL・メモなどのデータは送りません。通信失敗時は自動ダイアログを出さず、1時間以上空けて再確認します。
