# v0.3.0 実装と検証

## 実装した範囲

- ファイルURLのドラッグ開始で、操作中の有効なディスプレイのノッチに小型の棚を表示。接近時／手動にも切り替え可能。
- ドラッグ中はホバーによる自動クローズを抑止。取り込まずに終了・取消した場合は一時展開を閉じる。
- ブラウザ表示中は棚の領域を確保し、WebViewと重ねない。棚を閉じたら元のブラウザサイズに戻す。
- 参照とbookmarkの保存、重複防止、複数選択、コピーとしてのドラッグ取り出し、サムネイル、Quick Look、ピン留め、Finderで表示、手動ペースト、ダウンロード追加オプション。
- スリープ抑止30分／60分／解除、Core Audioで対応する既定出力の音量・ミュート、選択したmacOSショートカットの実行。
- 設定各タブの大きな見出し・説明文と色付き装飾を削除。サイドバーの選択はニュートラルな背景で表示。

## 確認結果

macOS 15.7.9 / Apple Siliconで実施。

- `swift test`: 25件成功。既存の選択表示・ホバー・更新通知テストに加え、保存・復元・重複・ピン留め・元ファイル保持・書込失敗・旧設定・ドラッグ状態・棚とブラウザの非重複を検証。
- 別bundle IDのオフラインプレビューで設定画面、棚、クイックスイッチのレイアウトを確認。
- 実際のAppKitドラッグセッションを検証用ウィンドウから開始。ノッチに近づく前に棚が開くことを画面で確認。棚へのドロップ後に保存とサムネイルを確認し、棚から検証用受信ウィンドウへファイルURLを取り出せることを受信結果で確認。
- Escでドラッグを取り消すと小型の棚が閉じることを確認。
- SpaceでQuick Lookにファイル内容が表示されることを確認。初回表示でウィンドウレベルがリセットされる問題を修正し、棚より前面（102、棚は101）に表示されることを確認。
- スリープ抑止をUIから開始し、`pmset -g assertions`で検証アプリのassertionを確認。解除後に同assertionが消えることを確認。既存の他プロセスのassertionは変更しない。
- 音量・ミュートは実機の現在値を読み取る表示を確認。検証のためにユーザーの出力状態は変更していない。

## 未検証・初期版の制限

- FinderのUI自動操作は環境の取得エラーがあったため、ドラッグの実動作検証は専用AppKitウィンドウ間で実施。Finder／Mail／各ブラウザ、複数画面・Spaces・フルスクリーンの総当たり検証は未実施。
- ドロップ時に生成されるファイルpromise、Web画像、テキストの保管は初期版に含めない。既存のファイル・フォルダを対象にする。
- 実機でのショートカット実行、全出力機器での音量・ミュート操作は未検証。対応しないプロパティは無効化する。
- macOS 26のLiquid Glass表示とIntelでの実行は未検証。両アーキテクチャのリリースビルドを作成する。
