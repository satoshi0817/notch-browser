# TASK-NOTCH-MEETING-NOTES-016

Notion 接続がある場合、固定タブ「議事録」を表示します。切断時は直前のブラウザタブへ戻ります。参加者は人数のみ表示し、ユーザー読み取り API は使用しません。内容は読み取り専用です。

右上の歯車からタブ内設定を開きます。「接続」「データ」「表示」と「‹ 戻る」はタスクタブと共通の構成です。データでは議事録を含むページまたはデータベースの URL を指定できます。空の一覧からも「議事録のページを指定」で開けます。

一覧は `POST /v1/blocks/meeting_notes/query`、`Notion-Version: 2026-03-11`、最大50件、ページングなしで取得し、新しい日時順に日付でグループ化します。`meeting_notes` と旧 `transcription` を読み取ります。未知の状態はその値をラベルとして表示します。

query が空の場合だけ URL を探索します。データベースは最大5データソース・各50ページ、子ブロックは深さ4・500件・100親・100リクエストで打ち切ります。本文は深さ6・500件・100リクエストまで取得し、013 の本文表示を使います。空の本文タブは非表示、既定は要約、なければメモ、次に文字起こしです。429 は Retry-After の秒数に従い最大2回再試行します。

## DEBUG プレビュー

DEBUG ビルドのアプリへ以下の起動引数を渡します。接続はプレビュー状態となり、議事録の保存・トークン取得・API 呼び出しを行いません。

- `--meetings=list`: 日付グループ、状態別ラベルの一覧
- `--meetings=detail`: 左の一覧で1件選択済みの分割表示。右に決定事項・次のアクションの要約、会議メモ、発言時刻付きの文字起こし
- `--meetings=progress`: 分割表示で作成中の議事録を選択済み。右にグレーの状態チップと「Notion で作成中です。しばらくしてから更新してください」（本文・詳細の更新ボタンは表示しない）
- `--meetings=empty`: 空の一覧とページ指定ボタン
- `--meetings=settings`: タブ内設定
- `--meetings=pinned-unconnected`: 設定›固定ページで議事録を選択、未接続の右側設定（接続グループは操作可能、データ・表示は無効）
- `--meetings=error`: 保存済み接続の確認失敗。タブは表示したまま、再確認・設定を開くバナーを表示し、歯車と一覧・詳細を隠す

Release ビルドではモック引数を無視します。

0.5.40向けの015a統合では、設定›固定ページの議事録とタブ内の歯車が同じ `NotionMeetingsSettingsPage` と `notionMeetings.fallback` を使用します。接続状態は015aの `NotionConnectionState` / `NotionTaskRules` に従い、トークン保存時から表示し、確認中は読み込みを表示します。未接続・未確認・無効なトークンではデータ設定を編集できません。接続に関する浮いた注記は表示しません。

DEBUGプレビューの接続状態はキーチェーンを読み書きせず、議事録モックは保存・API呼び出しを行いません。設定全体のプレビューには015aと同じ `--defaults-suite=<専用の名前>` を併用できます。DesignPreviewでは `--select-tab=meetings --notion-connection=verifying` で確認中、`--select-tab=meetings --notion-connection=invalid` で無効なトークンも確認できます。

## r2 表示修正

日付は `ja_JP` とグレゴリオ暦を明示し、一覧は「10月14日（水）」、詳細は「2026年10月14日（水）0:05」で表示します。状態チップは014と同じ10pt・横4pt/縦3ptの余白・角丸4pt・12%の背景色で、行の右端に配置します。作成中はグレー、失敗は赤です。

一覧ヘッダーは015のタスクと共通コンポーネントを使用し、更新・歯車の間隔8ptと外側の余白を揃えます。本文のセグメントには可視の「本文」ラベルを付けません。一覧行と詳細の右クリックメニューから「Notion で開く」を利用できます。

dd15847と比較し、固定タブをスクロール領域の外へ置く構成と、長いタイトルを先に縮める幅計算は維持しています。議事録ボタンにも再配置時の幅制約・別ウインドウ状態の解除を適用しました。通常タブの予約幅は常に150ptではなく、選択中（なければ先頭）の通常タブの自然幅を28〜150ptに制限した値とし、短いタイトルの余白が固定3タブを圧縮しないようにしています。

`NotchTabLayoutTests` に固定3タブの幅配分、通常タブ幅の予約、ノッチ/別ウインドウ切替時の制約解除を追加しました。`NotionMeetingsTests` には日本語の日付書式と本文モック・作成中モックの違いを追加しました。r2でも `swift test` は実行していません。

## 0.5.40 デザイナー修正

議事録のアイコンはタブ・固定ページ一覧とも `person.2` です。一覧と詳細は左右同幅、中央の区切り線はタスクと同じ1ptを予約します。未選択時は「議事録を選ぶと内容が表示されます」。更新・歯車は一覧側の上端右に置き、一覧へ戻るボタンはありません。日付見出しは上16pt・下5pt、行は36pt・区切り線付きで014に揃えています。

詳細は日時・所要時間・人数を「2026年10月14日（水）1:33・45分・3人」の1行で表示し、直下に「Notion で開く」リンクを置きます。作成中の更新は一覧上端のボタンを使います。

共通設定ページでは「議事録のページ URL」、枠付きの広い入力欄、「確認」を同じ行に配置します。空欄でも自動取得を確認できます。並び順は新しい順/古い順、表示件数は10/25/50件のメニュー型Pickerで変更・保存できます。取得APIは従来どおり最大50件です。モックでの設定変更は保存しません。
