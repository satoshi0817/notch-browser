# モーションの調整（2026-09-30）

提供画像のガイドにある、滑らかな加減速・重なりのある遷移・一つの対象への集中を、動画ではなくNotchBrowserの操作に適用した。Apple公式の仕様として扱ってはいない。

- ノッチの形と既存のGlassSurfaceを保つ。動きのための発光、バウンド、効果音は加えない。
- 開く際は枠の伸縮を先行させ、全体時間の12%後から内容をフェードイン。閉じる際は60%までに内容をフェードアウトする。
- 標準の開き方は減速する曲線、閉じ方は滑らかな加速・減速。ゆったり設定は始点・終点の加速度も連続する曲線を使う。
- 開閉の割り込み時は、実際のウィンドウ位置・大きさ・透明度・角丸を出発点とする。前のタイマーを破棄し、古い完了処理が後から戻すことを防ぐ。
- ファイル棚への縮小・展開にも共通の処理を使う。内容を保持する棚の仕様は変えない。
- カスタムの時間・待ち時間・一定速度・アニメーションなしは保持。「視差効果を減らす」は動きを省略。
- 設定画面内のプレビューは、同じ曲線とフェードのタイミングを使い、開く・少し保持・閉じるを確認できる。ブラウザを開いたりフォーカスを奪ったりしない。

短時間だけ動くTimerをcommon run-loop modeに登録し、表示中のフレームを直接更新する。[AppleのTimer資料](https://developer.apple.com/documentation/foundation/timer)に記載の通り、実行間隔は厳密な保証ではないため、コール回数ではなく単調増加の時刻から進捗を計算する。

33件のテストが成功。追加テストは曲線の単調性・オーバーシュートなし・フェードの前後関係・実ウィンドウの開閉反転・即時終了後の安定性を確認。独立Previewアプリでクイックスイッチの入口がないこと、設定内プレビューの静止／再生表示を確認した。実機の全リフレッシュレートでの滑らかさを保証するものではない。

One Switch相当のクイックスイッチは機能全体を削除し、関連コード・メニュー・Apple Events利用目的と署名entitlementも削除。以前その機能から変更されたmacOSの設定は更新時に書き換えない。
