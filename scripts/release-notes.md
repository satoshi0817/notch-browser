MacBook のノッチに住む小さなブラウザです。ノッチにカーソルを乗せるか `⌃⌥N` で開きます。

## 0.1.3 の変更点

- 設定画面が NotchBrowser のノッチより前面に表示されるようにしました
- 設定画面をカーソルのあるディスプレイで開くようにしました

0.1.2 以前から更新する場合は、NotchBrowser を終了してから `NotchBrowser.app` を置き換えてください。0.1.0 の設定とログイン情報も、初回起動時に自動で引き継がれます。

## インストール

1. `NotchBrowser-*.zip` をダウンロードして展開し、`NotchBrowser.app` を「アプリケーション」フォルダに移動します。
2. 開くと「Apple は検証できませんでした」と表示されます（Apple の公証を受けていないため）。
3. **システム設定 › プライバシーとセキュリティ** を開き、下の方にある「NotchBrowser」の **このまま開く** をクリックします。

ターミナルが使える場合は、次のコマンドでも開けるようになります。

```
xattr -dr com.apple.quarantine /Applications/NotchBrowser.app
```

## 動作環境

macOS 14 以降（Apple Silicon / Intel）。ノッチのない Mac や外部ディスプレイでは、画面上端の中央に表示されます。

## 主な機能

- 固定タブ（名前・URL・アイコン・アイコンのみ表示）、ドラッグで並べ替え
- プロファイルごとにログイン情報を分離
- ディスプレイごとの表示・待機時の不透明度・サイズ
- 次の予定までの分数をノッチに表示（Mac のカレンダーを使用）
- 画面共有・スクリーンショットに映らない
